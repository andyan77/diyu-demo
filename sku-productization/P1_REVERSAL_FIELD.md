# T3 · P1_REVERSAL_FIELD v1.0

## 缺口

Q-COMM-05 §7 M4 要求解释四件事：A 赢在哪里／B 为什么不选／代价是什么／**什么条件改变后裁决会反转**。前三项 P1 已有承载：
- A/B/代价：`creative_concept`（选中方向 + 为什么选它）+ 未选候选内部保留的"适用条件、代价与失败条件"（SKILL.md「核心判断」CS-1 节，"候选在用户选择前不得被确定性抹掉"一段）
- 第四项（反转条件）此前无承载字段。

## 新增字段

- **字段名**：`reversal_conditions[]`
- **位置**：SKILL.md「输出」块，`creative_concept` 之后、`audience_shift` 之前（命名风格与既有 `creative_directions[]`/`explicit_non_promise[]` 一致，采用 snake_case + `[]` 数组后缀）
- **内容规则**：
  - 每个未选候选一条：「若 X 成立，应改选它而非当前推荐」
  - X 取自该候选**已经保留**的适用条件（CS-1 一段已有的"未选候选……完整保留其五轴说明、适用条件、代价与失败条件"），**不是另起一套新判断**——这是把已有信息组织成明确输出
  - 候选数 = 1 时不得留空：写明"不存在真实取舍，因此无反转条件"，或写明"什么条件出现会产生真实取舍"
