# E2-P · P-1 迁移件：历史改动日志表

## 为什么搬

`SKILL_v2.0.md` 的全文（含下述历史改动日志表）会被 `resync_prompts.py` 逐字节拼进对应 DSL
的 `skill_llm` 系统角色提示词（拼接规则：`SKILL_v2.0.md` 全文 + `"\n---\n\n# 本次运行注入的参考文件片段"`
起始的固定附录）。这意味着表里的文字在运行时会被模型当作**现行输出要求**读，而表中写着
`return_to_script[]` 要写全七项——该字段本轮已被删除（见 `REMOVAL_TRACE.md`）。

这个判定只对**系统提示词**成立，对**文档**不成立：作为文档，这张表记录的是"v1.3→v1.4（或 m4
初版）曾经改了什么"这一历史事实，这个事实不因 v2.0 的后续删除而失真，改写它等于篡改历史。

处置：**搬走，不改写**。三份 `SKILL_v2.0.md` 里的表整段移出（不再进入运行时喂入），原文逐字保存在本文件；
DSL 系统提示词随 `SKILL_v2.0.md` 重新派生后自动不再包含这张表。
