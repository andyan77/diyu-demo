# 端到端案例

> **主本在 `publishing-packaging/references/examples.md`。** 另两份 Skill 下的同名文件是副本，改动必须三份同步。

**这份文件回答一个问题：规则被真的执行时，产出长什么样。**

四个案例，**没有一个是服装**——服装那一套（试穿、商品图、品类识别）在 SKILL.md 正文里已经举了很多次，再举就变成"这套 Skill 只会做服装"。

**每个案例只展示一件事**，不是完整的三段产出。每一件都带同一个对照：**没有这条规则我本来会写什么** → **有了之后我改成了什么**。看不出这个差别的例子，就不该出现在这里。

**用法**：不要通读。手上的活卡在哪一类判断上，就看对应的那一个。

---

## 一 · 餐饮｜把一个判断和一个物理状态拆开

**手上有**：一家 28 座小馆，油爆虾复炸时间从 15 秒加到 20 秒、又退回 18 秒。复盘记录原文：「壳更脆但虾肉略柴」。

**卡在哪**：这句话同时占两边。它是一次**前后变化**（PD-3 说必须用画面），也是**周姐的判断**（`SUBJECTIVE`，说了不得用画面强化）。两条都是硬规则。

**怎么解**：把「壳的物理状态」和「更脆／略柴」拆成两件事。物理状态可拍，判断不拍。

```
U-6  SHOT  虾倒进盘里，手捏起一只，拇指压壳。只收声，不给虾肉特写。
           目的：壳的物理状态（可拍）—— 不是"更脆"（那是判断）
           画面语言关系：补充 —— 台词说"壳是脆了，肉有点柴"，
                       画面只给壳，不给"柴"配任何虚指镜头
           ⚠️ 硬禁：不拍虾肉纤维、不拍周姐皱眉、不拍她放下筷子。
                    任何一个都会把"略柴"这个判断变成看起来客观的东西。
```

**本来会写**：给「肉有点柴」配一个虾肉纤维的特写，或者一个皱眉的反应镜头。这是最顺手的做法。
**改成之后**：那三样全部写成"不许拍"。

**注意最后那三行的形式**——它不是"注意 SUBJECTIVE 不要强化"，是**三个具体的不许拍什么**。摄影师看得懂，现场没有解释空间。**规则落到执行层的样子就是"不许拍 X"，不是"注意 Y"。**

## 二 · 户外｜「我答不出」怎么写才不是敷衍

**手上有**：一条高赞提问下有人说"我上周照你视频里那套配置去了，结果晚上冷得睡不着"。博主自己的睡袋是充绒 400g、舒适温标 −2℃。

**卡在哪**：观众问"那我该带多厚的睡袋"。这个问题**作者答不出**——他不知道那晚的风、地面温度、对方的体感。但"答不出"三个字直接说，读起来像推卸。

**怎么解**：答不出的部分明说答不出，**能给的那部分给足**，并且把"你需要补什么"变成一个具体的动作。

```
预埋问答｜「那我到底该带多厚的睡袋？」

「我这只是充绒 400 克、舒适温标 −2 度。这是我的参数，不是你的答案
 —— 温标写在标签上，你那晚的风和地面温度没写在任何标签上。
 你给我季节、车露还是背包、那晚最低温这三格，我能给你我会怎么带；
 你自己那一晚，得你自己兜。」
```

**本来会写**：「看你去哪儿、什么季节，一般 −5℃ 以下建议充绒 800g 以上。」——一个听起来很负责的通用建议，实际是把自己的参数当成别人的答案（这个行业的头号淘汰项）。
**改成之后**：给参数、给边界、给三个要对方自己填的格子。

配套的画面是同一条规则的另一半：

```
key_frame  第 19 秒 —— 手指停在标签下方的空白处，指尖没离开，
           标签上的 −2℃ 在同一画面里可读
           ⚠️ 手指停住之后，同一镜头内不得有任何后续动作进入
              （不得转向睡袋、不得皱眉）
```

这是 `KNOWN_UNKNOWN` 的画面边界：**只能呈现"这里是空的"，不得呈现"空的地方本来该有什么"。** 手一转向睡袋，"我不知道"就变成了"我知道，只是不说"。

## 三 · 知识付费｜素材荒的行业里，证据长什么样

**手上有**：讲师拒绝开"7 天速成爆款文案"班；一位学员的稿子改了三次、砍掉七成过程描述；一位退课学员的原话：「我以为学完就能写出那种一看就停不下来的文章，结果发现你教的是怎么把事情说明白。这个我好像本来就会。」

**卡在哪**：这个行业没有可拍的过程、没有可拍的物件。默认动作是坐着说话，画面切 PPT。

**怎么解**：**纸的厚度就是证据。**

```
scene_and_action
  桌上从左到右摆三摞纸 —— V1 / V2 / V3。他从右往左讲（先拿成稿，再往回翻）。
  全片他只做三件事：把一摞纸拿起来掂一下 | 翻到某一页用笔划一道 | 把纸推到画面外。
  不是「坐在书桌前说话」。

key_frame  0:58 —— 三摞纸并排俯拍，V1 明显最厚 V3 明显最薄，
           手指刚从 V1 移到 V2 上方。不出人脸、不出文字。
           单独截出来发给别人：看得懂 —— 三摞厚度不同的纸，一只手在上面。
           为什么不用他的脸：他不是这条内容的证据，纸才是。
```

**本来会写**：讲师中景口播，画面切改稿前后的截图对比。
**改成之后**：改稿前后的**体量差**变成一个可以掂在手里的物理量。

**标题的选法跟着变**：

```
recommended_title  「第三稿，砍掉了七成」（QUOTABLE_LINE，9 字）
指名兑现处：beat-3 逐字稿「改了三次。砍掉七成的过程描述。」
            ＋ 三摞纸厚度差、手指从 V1 划到 V3（0:52–1:10）

被淘汰的候选：「资深编辑的写作课，值不值得报？」
  淘汰理由：它承诺一个判定，而这条内容明说不给判定。
  观众带着"帮我决定"进来，第 60 秒听到"我给不出通用的改法"
  —— 这时的挫败感比信息量不足更强，因为他被承诺的是一个决定，
     拿到的是一个承认。
```

## 四 · 个人 IP｜五条规则同时指向"什么都不做"

**手上有**：创始人手机备忘录三条。其中一条：「我到现在也说不清，是我想让她们看到我在工作，还是我怕她们只看到我在工作。」上游禁令：孩子不露正脸。

**卡在哪**：这句台词情绪重，本能反应是配一个"若有所思"的收尾。

**怎么解**：

```
U5 | SHOT | 对应 beat-3 | 24–32s | 停驻

内容：机位完全不动。她把对折好的进货单放下，手从它上面移开
      —— 这是全片最后一个动作。然后说那句话。
      说完不动，不看镜头，画面继续 2 秒，黑场。环境声比画面晚 1.5 秒出。

这个单元的目的：变化 —— 桌面清空了，但人没有站起来。
                事情做完了，状态没往前走。
画面语言关系：制造信息差 —— 台词给了一个二选一，画面不指向任何一边。

三道硬关卡（不是提醒，是关卡）：
 1 全片唯一一次不得有任何视线移动。禁止转头、看窗外、抬眼看镜头。
   任何一次转头都会把"我说不清"变成"我知道是哪一边"。
 2 不得出现孩子 —— 含手、含衣角、含现场声。
   孩子入镜会让这句话变成"她在看孩子想的"。
 3 全段不得有任何剪辑点。一个切点就是一次画面上的断言。

字幕规则（透传下游）：这句可以上字幕（应当强化），
                    但只上一遍、不重复、不在结尾定格。
                    定格＝在呈现"空的地方本来该有什么"。
```

**本来会写**：镜头缓推，她抬头看向孩子的空座位，画面定格，黑场。**而且它看起来会很好。**
**改成之后**：机位不动、视线不动、不出现孩子、不切一刀。

**这一段值得单独记住的地方**：`KNOWN_UNKNOWN` 的画面边界、「停驻」必须写清为什么不能往前走、上游的未成年人禁令、镜头的目的、画面与语言的关系——**五条规则各自独立地指向同一个操作：什么都不做。**

## 五 · 一条贯穿四个案例的东西

四个案例的关键单元，写出来都长同一个样子：

**目的一句话 ＋ 画面语言关系一个词 ＋ 两到三条"不许拍什么"。**

不是「注意不要过度强化」，是「不拍虾肉纤维、不拍皱眉、不拍放下筷子」。
不是「保持克制」，是「不得转头、不得出现孩子、不得有剪辑点」。

**规则写成提醒，现场就有解释空间；写成禁令，就没有。** 这是这四个例子唯一共同的手法，也是它们能被照着做的原因。
