# 端到端案例

> **主本在 `publishing-packaging/references/examples.md`。** 另两份 Skill 下的同名文件是副本，改动必须三份同步。

**这份文件回答一个问题：规则被真的执行时，产出长什么样。**

**七个案例，没有一个是服装**——服装那一套（试穿、商品图、品类识别）在 SKILL.md 正文里已经举了很多次，再举就变成"这套 Skill 只会做服装"。

前四个是**视频**，关卡落在镜头上。后三个各代表一种**镜头之外的档位**——访谈提取（素材还没发生）、图文不新拍（没有镜头）、私域回应（起点不在公开处）——它们的失败根本不在画面里。

**每个案例只展示一件事**，不是完整的三段产出。每一件都带同一个对照：**没有这条规则我本来会写什么** → **有了之后我改成了什么**。看不出这个差别的例子，就不该出现在这里。

**用法**：不要通读。手上的活卡在哪一类判断上，就看对应的那一个。

---

## 一 · 餐饮｜把一个判断和一个物理状态拆开

**手上有**：一家 28 座小馆，油爆虾复炸时间从 15 秒加到 20 秒、又退回 18 秒。复盘记录原文：「壳更脆但虾肉略柴」。

**卡在哪**：这句话同时占两边。它是一次**前后变化**（PD-3 说必须用画面），也是**周姐的判断**（`SUBJECTIVE`，说了不得用画面强化）。两条都是硬规则。

**怎么解**：把「壳的物理状态」和「更脆／略柴」拆成两件事。物理状态可拍，判断不拍。

```
U-6  SHOT  虾倒进盘里，手捏起一只，拇指压壳。只收声，不给虾肉特写。
           目的：壳的物理状态（可拍）—— 不是"更脆"（那是判断）
           画面语言关系：补充 —— 台词说"壳是脆了，肉有点柴"，
                       画面只给壳，不给"柴"配任何虚指镜头
           ⚠️ 硬禁：不拍虾肉纤维、不拍周姐皱眉、不拍她放下筷子。
                    任何一个都会把"略柴"这个判断变成看起来客观的东西。
```

**本来会写**：给「肉有点柴」配一个虾肉纤维的特写，或者一个皱眉的反应镜头。这是最顺手的做法。
**改成之后**：那三样全部写成"不许拍"。

**注意最后那三行的形式**——它不是"注意 SUBJECTIVE 不要强化"，是**三个具体的不许拍什么**。摄影师看得懂，现场没有解释空间。**规则落到执行层的样子就是"不许拍 X"，不是"注意 Y"。**

## 二 · 户外｜「我答不出」怎么写才不是敷衍

**手上有**：一条高赞提问下有人说"我上周照你视频里那套配置去了，结果晚上冷得睡不着"。博主自己的睡袋是充绒 400g、舒适温标 −2℃。

**卡在哪**：观众问"那我该带多厚的睡袋"。这个问题**作者答不出**——他不知道那晚的风、地面温度、对方的体感。但"答不出"三个字直接说，读起来像推卸。

**怎么解**：答不出的部分明说答不出，**能给的那部分给足**，并且把"你需要补什么"变成一个具体的动作。

```
预埋问答｜「那我到底该带多厚的睡袋？」

「我这只是充绒 400 克、舒适温标 −2 度。这是我的参数，不是你的答案
 —— 温标写在标签上，你那晚的风和地面温度没写在任何标签上。
 你给我季节、车露还是背包、那晚最低温这三格，我能给你我会怎么带；
 你自己那一晚，得你自己兜。」
```

**本来会写**：「看你去哪儿、什么季节，一般 −5℃ 以下建议充绒 800g 以上。」——一个听起来很负责的通用建议，实际是把自己的参数当成别人的答案（这个行业的头号淘汰项）。
**改成之后**：给参数、给边界、给三个要对方自己填的格子。

配套的画面是同一条规则的另一半：

```
key_frame  第 19 秒 —— 手指停在标签下方的空白处，指尖没离开，
           标签上的 −2℃ 在同一画面里可读
           ⚠️ 手指停住之后，同一镜头内不得有任何后续动作进入
              （不得转向睡袋、不得皱眉）
```

这是 `KNOWN_UNKNOWN` 的画面边界：**只能呈现"这里是空的"，不得呈现"空的地方本来该有什么"。** 手一转向睡袋，"我不知道"就变成了"我知道，只是不说"。

## 三 · 知识付费｜素材荒的行业里，证据长什么样

**手上有**：讲师拒绝开"7 天速成爆款文案"班；一位学员的稿子改了三次、砍掉七成过程描述；一位退课学员的原话：「我以为学完就能写出那种一看就停不下来的文章，结果发现你教的是怎么把事情说明白。这个我好像本来就会。」

**卡在哪**：这个行业没有可拍的过程、没有可拍的物件。默认动作是坐着说话，画面切 PPT。

**怎么解**：**纸的厚度就是证据。**

```
scene_and_action
  桌上从左到右摆三摞纸 —— V1 / V2 / V3。他从右往左讲（先拿成稿，再往回翻）。
  全片他只做三件事：把一摞纸拿起来掂一下 | 翻到某一页用笔划一道 | 把纸推到画面外。
  不是「坐在书桌前说话」。

key_frame  0:58 —— 三摞纸并排俯拍，V1 明显最厚 V3 明显最薄，
           手指刚从 V1 移到 V2 上方。不出人脸、不出文字。
           单独截出来发给别人：看得懂 —— 三摞厚度不同的纸，一只手在上面。
           为什么不用他的脸：他不是这条内容的证据，纸才是。
```

**本来会写**：讲师中景口播，画面切改稿前后的截图对比。
**改成之后**：改稿前后的**体量差**变成一个可以掂在手里的物理量。

**标题的选法跟着变**：

```
recommended_title  「第三稿，砍掉了七成」（QUOTABLE_LINE，9 字）
指名兑现处：beat-3 逐字稿「改了三次。砍掉七成的过程描述。」
            ＋ 三摞纸厚度差、手指从 V1 划到 V3（0:52–1:10）

被淘汰的候选：「资深编辑的写作课，值不值得报？」
  淘汰理由：它承诺一个判定，而这条内容明说不给判定。
  观众带着"帮我决定"进来，第 60 秒听到"我给不出通用的改法"
  —— 这时的挫败感比信息量不足更强，因为他被承诺的是一个决定，
     拿到的是一个承认。
```

## 四 · 个人 IP｜五条规则同时指向"什么都不做"

**手上有**：创始人手机备忘录三条。其中一条：「我到现在也说不清，是我想让她们看到我在工作，还是我怕她们只看到我在工作。」上游禁令：孩子不露正脸。

**卡在哪**：这句台词情绪重，本能反应是配一个"若有所思"的收尾。

**怎么解**：

```
U5 | SHOT | 对应 beat-3 | 24–32s | 停驻

内容：机位完全不动。她把对折好的进货单放下，手从它上面移开
      —— 这是全片最后一个动作。然后说那句话。
      说完不动，不看镜头，画面继续 2 秒，黑场。环境声比画面晚 1.5 秒出。

这个单元的目的：变化 —— 桌面清空了，但人没有站起来。
                事情做完了，状态没往前走。
画面语言关系：制造信息差 —— 台词给了一个二选一，画面不指向任何一边。

三道硬关卡（不是提醒，是关卡）：
 1 全片唯一一次不得有任何视线移动。禁止转头、看窗外、抬眼看镜头。
   任何一次转头都会把"我说不清"变成"我知道是哪一边"。
 2 不得出现孩子 —— 含手、含衣角、含现场声。
   孩子入镜会让这句话变成"她在看孩子想的"。
 3 全段不得有任何剪辑点。一个切点就是一次画面上的断言。

字幕规则（透传下游）：这句可以上字幕（应当强化），
                    但只上一遍、不重复、不在结尾定格。
                    定格＝在呈现"空的地方本来该有什么"。
```

**本来会写**：镜头缓推，她抬头看向孩子的空座位，画面定格，黑场。**而且它看起来会很好。**
**改成之后**：机位不动、视线不动、不出现孩子、不切一刀。

**这一段值得单独记住的地方**：`KNOWN_UNKNOWN` 的画面边界、「停驻」必须写清为什么不能往前走、上游的未成年人禁令、镜头的目的、画面与语言的关系——**五条规则各自独立地指向同一个操作：什么都不做。**

## 五 · 餐饮访谈｜关卡落在日程表上，不落在镜头上

**手上有**：两位当事人（主厨、店长）各一场访谈，**都还没进行**。一次分歧：店长提议换半成品大肠省掉九道清洗，主厨拒绝，最后改成限量每天 15 份。

**卡在哪**：访谈还没做 → 事实=无、素材=待产出·不可控 → **只能出提问清单和结构骨架，不得写对方的话**。但真正会砸的地方不在这儿。

### 第一件事：兑现物不许挂在还没发生的答案上

方向选择阶段就要问一句：**这个方向的兑现物，「事实」那一栏是「有」还是「无」？**

```
被淘汰的方向：「两个人各自说出理由，观众听完明白两边都对。」
  淘汰理由：它的兑现物必须是「菜单后来怎么改的」，而输入里没有任何改菜单的记录。
           要么落空，要么赌受访者临场给出一个输入外的方案。
           张力是真的，兑现物是假的。

选中的方向：落点那一段全部由屏幕文字和已有空镜承担，事实=有。
           访谈答案负责「为什么这么想」，不负责「结论成不成立」。
```

**本来会写**：落点＝两个人各自说出理由。五轴写出来漂亮，纸面上完全看不出问题。
**改成之后**：**张力可以挂在待采集的答案上；兑现物不行。**

砸的机制很具体：访谈回来只要一个人说不到点，全片没有落点——**而这时人已经走了，按禁令不能补录。**

### 第二件事：提问清单是对**采集工具**的约束

```
❌ 「你当时为什么拒绝店长换半成品大肠的提议？」
   一句话装进了三条已知事实（是店长提的／提的是换半成品／你拒绝了）。
   受访者只剩补充动机的余地。他顺着复述之后，剪出来的那句"原话"，
   实际上是我们写的话由他念了一遍。这不是编造，比编造更难查。

✅ 「有人跟你提过省掉一部分吗？谁提的、怎么提的？」（不预设是谁、是什么、结果如何）
✅ 「我这次是带着「这是一次分歧」来问的——你觉得这算分歧吗？」（允许推翻整条内容的前提）

两条可判定的检查：
① 逐条划掉问题里出现的输入专有名词（半成品／15 份／店长／拒绝／九道）。
   划完还问得出来的，才算合格问题。
② 全清单至少有一问，它的合格答案是「你这个前提不成立」。
```

### 第三件事：关卡落在日程表上

```
同题单元完整性关卡：
  任一同题单元若只拿到一人答案，该单元整体删除，不得单边保留。

日程表：
  离场前 90 分钟 | 现场粗排：逐个同题单元做完整性检查 | 剪辑必须在店里

为什么剪辑师必须当天在场：「不得补拍对白」意味着素材缺口无法事后补救。
哪一个同题单元只拿到一人答案，必须在人还没走之前发现——
发现之后的合法动作只有两个：用剩下的提问再问一次（同一场访谈内，未收工），
或当场决定删掉该单元。走出店门再发现，就只剩删。
```

**本来会写**：「若某一方的答案不可用，保留另一方的回答，缺的那半用事实卡补上。」——最顺手的救场，看起来还很负责任（不编造、用已知事实顶上）。它顶出来的结果正是"一方真人 ＋ 一方文字卡"，也就是禁令要防的独白。

**这一档值得单独记住的地方**：前四个案例的关卡全部落在镜头上（不许拍什么）。**访谈提取的失败根本不发生在镜头里——它发生在"人已经走了"这个时刻上。** 所以关卡也不在镜头上，在日程表上和提问清单上。

## 六 · 图文不新拍｜没有镜头时，边界的载体是翻页

**手上有**：三位学员的初稿与成稿、30 张批注截图。**不新拍，纯图文。**

### 分屏＝断言，同屏＝并存

```
U8 的两行文字必须同屏：

  完读率上去了
  他自己觉得不够严谨

分到两张图上，就变成了先扬后抑的叙事；同屏才是并存。

机械关卡：两行不得分屏。若截图比例导致必须分屏，
         回改为并列版式，不得拆成两图。
```

**本来会写**：两行分两张图——翻页节奏更好，而且看起来更有层次。
**改成之后**：强制同屏。

**这是 `KNOWN_UNKNOWN` 的边界在无镜头媒介里的完整形态**：案例二、案例四把它写成镜头动作（"手指停住之后不得转向睡袋""不得转头、不得有剪辑点"）。图文没有镜头也没有剪辑点，**边界唯一的载体是翻页**。

### 不许把"我们知道的事"排版成"截图的样子"

```
批注截图糊了、看不清怎么办？

❌ 誊抄批注文字，重新排成截图样式。每个字都是真的，只是重新排了一遍。
❌ 用别的句子替代，或自己写一句"大意是……"

✅ 换揭晓物：改成"初稿与成稿的差异定位"，并在正文注明这一版没有批注、原因是原图不可读。
✅ 要放大只能用同一张原图。

通行原则一句话：素材不够就改讲法或减轮次，
              永远不许把"我们知道的事"排版成"截图的样子"。
```

**不拍摄的档位没有摄影机，伪造不从镜头进，从版式进。** 而且这是一种前四个案例里没出现过的伪造形态——**每个字都有来源，编的是"它是一张截图"这个身份。**

### 顺带一条：统一宽度，但不套统一模板

```
所有截图按同一宽度对齐，但不套统一模板。
律师文书、情绪散文、技术复盘三种稿面本来就长得不一样——
那个不一样本身是信息，抹平了就少了一层证据。

允许统一的只有一项：外框宽度。
不统一底色／边框／圆角／字体，不把三份稿面缩放到同一密度。
```

案例三的动作是**加**一个物理演出（摆三摞纸、掂一下）；这一条的动作是**减**一个设计层。防的是"把证据做得很整齐"。

## 七 · 私域回应｜起点不在公开评论区时，主客场有第三档

**手上有**：一句从**客服渠道**转来的顾客提问。品牌自己也不知道对方的肤质、买的哪一支、这一个月怎么用的。

**卡在哪**：PP-5 只有主场和客场两档。这条内容**是从别处的提问长出来的**（按定义是客场），但**没有"原提问所在的那条"可以置顶**——它不在任何公开讨论区。

### 第三档怎么处置

```
按主场处理（议题由这条内容自己设定，观众看不到原提问），但：

· 不存在"原提问那条下面"的第二处置顶落点。不要去找，也不要暗示它存在。
· 不得引用、概括或形容任何公开讨论——这条内容之外没有讨论，说有就是编造。
· constraints[] 机械关卡：不得出现「评论区有人问」或任何暗示公开讨论存在的表述。
```

**本来会写**：「评论区好多人问要不要回购」——把一条私域原话写成公开讨论，用"好多人"给它加量。最顺手的一步，而且看上去完全正常。

配套的"我答不出"，和案例二不是同一种：案例二的博主至少拿得出**自己的那份参数**，这里**连那个都没有**。

```
「我不知道。我不知道你的肤质，不知道你买的是哪一支，
  不知道你这一个月怎么用的。这不是客气——这三条我一条都没有。」

⚠️ 这段话里不得出现任何指代那位顾客的性别词。输入没写就不写（CS-7 ⑤）——
   一个明确宣称"我什么都不知道"的人，在同一句里断言了对方的性别，是这份材料
   原始版本真实犯过的错，而且它出现在全片立意所在的那一句上。
```

### 关键证据拍不到时，回改要连指示代词一起改

前四个案例都停在"这一条该怎么拍"，**没有一个演过"拍不到之后怎么办"**。

```
如果那个写字过程无论如何拍不清：

1 不做：找人代拍手部、用素材库的写字镜头、后期加动画字。
        （不得由第二人补拍手部——那不是他的手，构成伪造）

2 做：三行改由硬字幕逐行浮现承担，
      同时台词改一个词——把「我能给的是这三行」改成「我能给的就三条」。
      因为这时纸上已经没有可见的三行了，说"这三行"是在指一个观众看不到的东西。

3 连带回改：key_frame 失效，改用空白纸那一帧；封面和首帧同步改。

4 落点不变：三栏仍然被交出去了，只是换了一个通道。
```

**这才是回改，降低承诺不叫回改。** 第 2 步那半句——**换了通道就必须改指示词**——是这一整档里最容易被略过的一条：留下一句指着不存在画面的台词，观众在成片里找不到那三行。

## 八 · 一条贯穿七个案例的东西

七个案例的关键单元，写出来都长同一个样子：

**前四个的关卡落在镜头上（不许拍什么）。后三个证明了一件事：媒介换掉之后，关卡的落点跟着换——落到日程表上、落到翻页上、落到指示代词上。形式没变，位置变了。**


**目的一句话 ＋ 画面语言关系一个词 ＋ 两到三条"不许拍什么"。**

不是「注意不要过度强化」，是「不拍虾肉纤维、不拍皱眉、不拍放下筷子」。
不是「保持克制」，是「不得转头、不得出现孩子、不得有剪辑点」。

**规则写成提醒，现场就有解释空间；写成禁令，就没有。** 这是这七个例子唯一共同的手法，也是它们能被照着做的原因。
