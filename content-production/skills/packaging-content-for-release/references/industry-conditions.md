# 行业条件表

> **主本在 `publishing-packaging/references/industry-conditions.md`。** 另两份 Skill 下的同名文件是副本，改动必须三份同步。

**用法：按 `subject_domain` 只读对应的那一块，不要通读。** 五块之间没有共同结构上的依赖，读多了只会把别的行业的手法带过来。

**这张表回答的是「这个行业的现实条件是什么」**，不回答「这个行业该做什么内容」——后者是 SKILL.md 的判断，不搬到这里。

`subject_domain` 不在这五个里时：**不加载任何一块，按通用处理并在 `assumptions[]` 声明**。不要挑一个"最像的"套上去——套错行业比不套更贵，因为它带来一整套不成立的默认前提。

## 服装 / 门店零售

| | |
|---|---|
| **常见素材形态** | 试穿视频（长、未剪、未编目）｜商品图（棚拍，干净但不带信息）｜陈列照｜空镜 |
| **哪一类真的带信息** | **只有试穿视频**。棚拍商品图在信息流里和所有服装广告长得一样，基本只能当背景 |
| **可用的真实摩擦** | 选品会上被否掉的款｜顾客原话｜同一件在不同体型上的结果差异｜退货理由｜"想留但成本算不过来" |
| **特有淘汰项** | **① 用成分推性能**——"70% 羊毛所以垂感好、不起球"。成分是事实，性能是结论，中间那一步没有来源。要说垂感，只能用试穿时观察到的动作（手一松塌不塌）<br>**② 无条件推荐**——"必买""闭眼入"<br>**③ 把条件句写成否决句**——"取决于内搭体积"不是"我劝你别买" |
| **拍摄条件** | 门店光是混色温的（射灯 ＋ 自然光），白平衡容易翻车｜试衣间退不开，广角畸变｜**"塌"和"挺"只有动态能看出来**，平铺图拍不出来，必须穿着状态下拍 |
| **包装差异** | 封面用**穿着状态**不用平铺；在点击型平台上，封面里那件衣服要能一眼看出是什么品类——认不出品类的封面等于没有封面 |

## 餐饮 / 门店

| | |
|---|---|
| **常见素材形态** | 备料过程（长、脏、真实）｜成品图｜店内环境｜顾客镜头（需授权） |
| **哪一类真的带信息** | **备料过程**。成品图是这个行业最没有区分度的素材——所有餐饮内容的成品图都长一样 |
| **可用的真实摩擦** | 拒绝一个高频需求（"这道菜不天天供应"）｜成本算不过来的菜｜出餐时间和口味的取舍｜食材当天没到只能改菜单 |
| **特有淘汰项** | **① 无来源的工艺形容**——"秘制""古法""匠心"<br>**② 把后厨拍干净**——干净到不像在用的后厨反而不可信<br>**③ 用别家的成品图**<br>**④ 把"好吃"当成可证明的事实**——它是 `SUBJECTIVE`，不得用画面强化 |
| **拍摄条件** | 后厨高温、油烟、噪音大——**现场声通常吃掉人声，必须另录**｜备料时段和营业时段冲突，可拍窗口窄｜**火、油、水汽是天然的动作**，PD-5 在这个行业最好做，不需要额外设计"人在做什么" |
| **包装差异** | 首帧用**过程**不用成品；收藏动机来自"我也想试试这个做法"，转发动机来自"带你去吃"——两者的标题写法不同 |

## 知识付费 / 课程

| | |
|---|---|
| **常见素材形态** | 学员作业前后对比｜上课录屏｜讲师口播｜学员访谈（**多数还没发生**） |
| **哪一类真的带信息** | **改稿痕迹本身**——第几版改了什么。这个行业真正的素材是文字，不是画面 |
| **可用的真实摩擦** | 拒绝开速成班｜一个学员没学会｜把某个模块砍掉的决定｜退款案例｜讲师自己也没想明白的问题 |
| **特有淘汰项** | **① 学员成果当成方法有效的证明**——那是幸存者，不是验证<br>**② 时间承诺**——"三天学会"<br>**③ 把讲师的判断包装成行业共识**<br>**④ 访谈还没做就先写好学员会说什么**——这是最常见也最难发现的一种，因为写出来的稿子看上去完全正常 |
| **拍摄条件** | 最常见的档位是"一个人 ＋ 一台手机"｜**素材荒是常态**：没有可拍的过程、没有可拍的物件。这个行业要靠**版式和文字**承担表达，PD-5 的兜底出口（"只能靠文字与版式扛"）在这里是主路径不是备用路径 |
| **包装差异** | 长档为主，收藏动机来自**可复用的信息**（"存下来照着做"）｜标题**不能承诺结果，只能承诺方法**——承诺结果就落进上面第②条 |

## 动漫 / 原创 IP

| | |
|---|---|
| **常见素材形态** | 分镜（含**废弃分镜**）｜设定集｜原画｜配音｜已完成片段 |
| **哪一类真的带信息** | **废弃分镜**。它是这个行业唯一天然带"真实摩擦"的素材——一个被否掉的版本，本身就是一次可展示的取舍 |
| **可用的真实摩擦** | 创作决定本身就是摩擦（否决给某个角色正脸）｜改了三版的镜头｜做不出来的效果｜设定上必须放弃的东西 |
| **特有淘汰项** | **① 两层事实不分层**——设定层的"真"和现实层的"真"必须在画面上分开，否则观众把创作决策当成剧情<br>**② 用"世界观宏大"代替具体设定**<br>**③ 角色一致性断裂**——同一角色在两个单元里不像同一个人。这是这个行业的头号废片原因，且**在分镜阶段就要设一致性锚点**，不能留到成片才发现 |
| **拍摄条件** | 不拍摄，**产能是唯一约束**｜低资源 ≠ 减人，是**不动用新产能**——用废弃分镜、已有素材、纯文字卡替代需要新画／新生成的单元｜**声音是设计出来的、不是收来的**：纸张声、脚步声、器物声往往是这个 IP 的核心资产，不能因为"不是实拍"就整块跳过 |
| **包装差异** | 封面必须出现角色，且是**已定稿的那一版**（用废弃版做封面＝对外承诺了一个不存在的角色）｜转发驱动是"这说的是我"（Identity），不是"有用"（Utility） |

## 户外 / 露营（爱好垂类）

| | |
|---|---|
| **常见素材形态** | 现场视频（风噪严重）｜装备图｜路线图｜**评论区提问** |
| **哪一类真的带信息** | **评论区提问**。这个行业大量内容本来就是从别人的问题里长出来的——那是客场，见 PP-5 |
| **可用的真实摩擦** | 拒做新手清单｜某次装备失效｜天气逼停的计划｜**评论区里问的问题作者答不出** |
| **特有淘汰项** | **① 把自己的参数当成对方的答案**——"充绒 400g、舒适温标 −2℃"是我的参数，不是你该带多厚的答案。这是这个行业最高频的一种超额承诺<br>**② 装备推荐不说使用条件**<br>**③ 把一次好天气的体验当成常态** |
| **拍摄条件** | **风噪**——缩到 50cm 救不了，反而把广角畸变推到脸上；改成常规 80–100cm ＋ 选背风位 ＋ 贴身另录音轨后期对轨｜**天光窗口**——日出后一小时内或日落前两小时｜低温掉电｜**无监看**：PD-1 的"前两遍当热身"在没人看监视器时变成"每遍拍完必须回放"，工时翻倍｜地面是唯一置景面｜**完成日期取决于天气，不取决于工时**——资源档里写"几个天光窗口内"，不写"几小时" |
| **包装差异** | 评论区是主场景，客场情况下置顶要落**两处**（新内容下 ＋ 原提问那条下面）｜必须准备一个诚实的"我答不出"，代答就是编造 |

## 一条跨行业的提醒

**「创始人／个人 IP 出镜」不是一个行业**，它是服务对象维度上的一层，可以叠在上面五个中的任何一个上。

叠上去之后多出来的东西**不来自这张表，来自 `constraints[]`**：家人是否入镜、未成年人是否露正脸、哪些生活场景不可拍。

**这些是上游给的禁令，不是行业惯例，不得从这张表里推导，也不得因为"上游没写"就默认可拍。**
