# M3 语义成稿 → 工程编译交接边界

## 1. 交接状态

```text
planning_semantic_source     = FROZEN_FOR_ENGINEERING_INPUT
project_repository_write     = NOT_PERFORMED
dify_integration             = NOT_STARTED
runtime_truth_check          = REQUIRED

```

本目录是规划侧成稿，不是项目仓库提交。执行侧取得单独施工授权后，才可在独立任务分支编译、集成、验证与交付。

## 3. 执行侧必须先核验的事实

施工前只读核验：

1. 远程默认分支、当前 HEAD 与 M0 已接受合同的实际版本；
2. 六份现有 Skill 的当前源文件、附件、Dify 工作流、实际模型与参数；
3. M1、M2、M4 并发任务的实际分支和共享文件占用；
4. 当前 M2 对 M3 可提供的投影、版本、发布、反馈和权限语义；
5. Content Brief 可接收的合法等价输入和当前硬锁；
6. Campaign 覆盖与周期基线的当前接口；
7. 实际 Runtime 主模型与独立核验层。不得把历史“DeepSeek V4 Flash/Qwen 备选”或任何研究假设写成当前事实。

若核验结果只影响 HOW，执行侧自行选择最短路径并记录；若与本稿产品语义冲突，返回证据，不自行重写本稿。

## 4. 允许执行侧决定的 HOW

- Skill 源文件在项目内的具体路径和命名版本；
- Dify 单节点、适配层或有限节点组合；
- references 的条件加载方式；
- M2 投影到 M3 输入的字段映射；
- 输出结构、JSON/YAML/DSL 载体和版本策略；
- 日期、容量、去重等最小确定性工具是否需要及归属；
- 测试脚本、回放、日志与证据文件形式；
- 分支、提交、远端采用与技术收口方式。

这些选择不能制造新的产品字段义务、用户表单、固定调用顺序、状态机或审批流。

## 5. 不得由执行侧改变的 WHAT

- M3 的责任边界和四类业务行为；
- 目标忠实及目标间实质差异；
- 阶段成熟度、临时覆盖、动作和健康假设的分离；
- 期望量、基线产能和实际产能的分离；
- 稳定兑现与受控探索无固定配额；
- 证据成熟度与当前使用决定分离；
- 服装局部失效与声明特定证据；
- 主动市场机会的可逆验证语义；
- Campaign 只覆盖点名位置并回到当前有效基线；
- M3 到 Brief 的业务本体及停止边界；
- 六 Skill 是适用能力义务，不是强制全链；
- 反馈最小影响与有依据保持不变；
- 用户调整必须产生实际处理；
- 日常运行不引入 Founder 审核；
- M3 模块验收与 M5 成品增益验收分离；
- 不提前宣称真实运营或经营提升。

## 6. 工程编译规则

1. 先从 `SKILL.md` 编译最短可运行源，不把主稿全文塞入 Runtime。
2. references 按运行行为和行业条件加载，不得每次全量加载。
3. 不复制高频变化平台规则；需要时读取当前真源。
4. 不把夹具答案写进 Runtime；夹具用于验收，不用于提示答案。
5. 对每个新增字段、规则、节点和附件执行消融：删除后结果不变则删除或合并。
6. 对每条专业规则绑定失败模式、适用产物和至少一个正向/负向或反事实夹具；无夹具规则不得单独阻断 DONE。
7. 先完成模块级验收，再进入 M5 集成增益；不得用 M5 成品指标倒逼 M3 越权写创意和制作。
8. 完成定义满足后停止功能扩张，只允许记录证据、修复验收内缺陷与收口。

## 7. 最小正式验收

### 模块级

- 目标反事实族；
- 同目标不同阶段；
- 转化覆盖/衰退假设；
- 日三条、产能两条；
- 稳定兑现与探索；
- 服装局部失效；
- GMV/线索/到店区分；
- 市场机会与追热点区分；
- 反馈局部影响/保持不变；
- Campaign 覆盖与回归；
- 栏目缩减/暂停/退出；
- 合法直接入口和无任务结论；
- 至少一条跨周期连续运行。

### 集成级

- 同模型、同输入、同权限、同参数、同预算的合格基线 A/B；
- 人工盲评；
- 适用维度可 `NOT_APPLICABLE`；
- 只声明冻结验收集上的增益。

## 8. 并发与项目保护

M1、M2、M4 可柔性并行，M3 可稍后启动。执行 M3 时：

- 从当时远程默认分支建立独立任务分支；
- 不在共享工作树切换分支或覆盖其他窗口未提交内容；
- 先确认受影响文件占用；
- 对共享合同与索引采用最小串行收口；
- 不修改规划侧宪法协议或把它们放入项目仓库；
- 不因本稿存在而自动取得施工、外部发布、主干合并或真实账号权限。
