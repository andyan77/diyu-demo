## 二、三份场景（请逐份亲自跑）

每份都是**新开一个对话**。请照抄输入，或用你自己的话说同一件事——两者都应该work。

### 场景一｜完整主故事：从一句诉求到下一个周期

**第 1 句**（可以直接粘贴）：

> 我是序里集 XULI SELECT 品牌号。这周主推秋冬新款廓形西装外套，库存充足、可以出镜。内容说给 28-38 岁城市通勤女性听：她衣柜里通勤衣服不少，但每天早上还是要试好几套才敢出门，总觉得穿出去不够精神。我希望她看完能明白——不是衣服不够多，是缺一件能压住整套的外套，并且知道怎么用它三天不重样。表达上只讲穿搭方法和真实上身效果，不做剧情、不碰争议话题，不承诺瘦身或改变身材。帮我把这周的内容制作依据定下来。

**第 2 句**：`这条我已经发出去了。`
**第 3 句**：`收到的反馈是：播放比上周高一些，评论里问得最多的是这件外套配什么裤子。`
**第 4 句**：`这个周期就到这里，开下一个周期吧。`

**应该看到**
- 第 1 句之后给出一份**能直接拿去做内容**的制作依据，不是提纲、不是套话；
- 它明确说清楚哪些是**需要你拍板**的（比如本周做几条、发哪个平台、承接路径）；
- 第 2 句之后明确说明这是**测试记录**，没有对任何真实平台做操作；
- 第 3、4 句之后如实说出**这一轮真的记下了什么**；
- 全程**不出现** `READY`、`PASS`、`DELIVERED`、`CONTENT_BRIEF`、`ENTRY-03`、
  `audience_problem` 这类词，也不出现任何 ID 或节点名。

**不可接受**
- 声称已经发布到真实平台；
- 说某件事「已完成」但其实没写进系统；
- 把内部字段名或状态词直接抛给你；
- 要求你重复已经说过的内容。

### 场景二｜直接专业入口：不走全链，直接要一样东西

**新开一个对话**，只说一句：

> 这条内容的口播稿帮我写出来，从开头第一句到结尾都要能直接念。

**应该看到**
- 它**直接进入脚本**这件事，不先把账号矩阵、战役、Brief 全跑一遍；
- 信息不够时，它只问**真正卡住的那一项**，不是抛一张问题清单；
- 语言是人话。

**不可接受**
- 为了「流程完整」先补跑上游模块；
- 自己替你编一个内容方向或商品就往下写；
- 一次抛给你一堆要填的东西。

### 场景三｜缺口与撤回：它该在哪停、撤回到底影响什么

**新开一个对话。**

**第 1 句**：`这周想发点东西，你看着办吧。`

**应该看到**：它**停下来问你那一件真正缺的事**（比如主推什么、说给谁听），
**不自己挑商品、不自己定方向**；同时不依赖这项缺口的部分照常给你，不是整件事拒绝。

**第 2 句**：补上你的商品和受众（用你自己的话）。
**应该看到**：同一个对话里接着往下做，**不要求你重说一遍**前面给过的内容。

**第 3 句**（先上传任意一份 `.md` 资料，再说）：`刚才那份素材撤回吧，以后别再用了。`

**应该看到**它把四件事**分开**说清楚：
1. 这份素材以后不再用于新内容；
2. **已经发出去的内容不受影响、也没有被删除**；
3. **没有对任何真实平台做操作**；
4. 这一轮实际写进系统的是什么。

**不可接受**
- 把撤回说成「已发布内容也一并失效/删除」；
- 声称做了平台操作；
- 没写成功却说撤回已完成。

## 三、必须说清楚的非承诺

- **真实平台发布未验证，本应用也不做。** 所有发布记录都显式标为测试与模拟。
- **真实经营提升（涨粉、成交、到店）未验证。** 反馈是你手工告诉它的观察，
  不代表真实平台效果，也不构成经营效果证据。
- **M5 阶段已接受的八项技术债 `TD-M5-01..08` 未在本轮偿还**，仍然有效。
- 当前为**测试域**：每个新对话自建隔离的测试工作区与测试账号，写入的都是测试数据。
