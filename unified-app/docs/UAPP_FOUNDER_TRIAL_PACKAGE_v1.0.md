## 三、三份场景（建议按顺序试）

### 场景一｜完整主故事

**第 1 句**：

> 我是序里集 XULI SELECT 品牌号。这周主推秋冬新款廓形西装外套，库存充足、可以出镜。内容说给 28-38 岁城市通勤女性听：她衣柜里通勤衣服不少，但每天早上还是要试好几套才敢出门，总觉得穿出去不够精神。我希望她看完能明白——不是衣服不够多，是缺一件能压住整套的外套，并且知道怎么用它三天不重样。表达上只讲穿搭方法和真实上身效果，不做剧情、不碰争议话题，不承诺瘦身或改变身材。帮我把这周的内容制作依据定下来。

**第 2 句**：`这条我已经发出去了。`
**第 3 句**：`收到的反馈是：播放比上周高一些，评论里问得最多的是这件外套配什么裤子。`
**第 4 句**：`这个周期就到这里，开下一个周期吧。`

**该看到**：第 1 句产出能直接拿去做内容的制作依据，并明确标出需要你拍板的事；
第 2 句之后明确说明这是测试记录、没有对真实平台操作；全程不出现内部状态词或字段名。
**已知风险**：第 1 句可能改为反问你「这条内容对观众的承诺是什么」——这就是 TD-UAPP-01。

### 场景二｜直接专业入口

新开对话，只说：`这条内容的口播稿帮我写出来，从开头第一句到结尾都要能直接念。`

**该看到**：直接进入脚本，不先把账号矩阵、战役、Brief 全跑一遍；信息不够时只问卡住的那一项。

### 场景三｜缺口与撤回

新开对话。**第 1 句**：`这周想发点东西，你看着办吧。`
**第 2 句**：补上你的商品和受众。
**第 3 句**（先上传一份 `.md` 资料）：`刚才那份素材撤回吧，以后别再用了。`

**该看到**：撤回后把四件事分开说——未来不再复用 / 已发布内容不受影响 / 未对平台做任何操作 /
本轮实际写入了什么。
**已知风险**：第 1 句大概率一次问三件事（TD-UAPP-03）。
