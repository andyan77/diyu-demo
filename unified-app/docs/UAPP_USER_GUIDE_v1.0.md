# 笛语 V1 统一入口 · 一页用户指南

**应用名**：DIYU V1 · Unified Founder Canvas
**怎么打开**：Dify 工作台 → 应用列表 → 打开这个应用 → 「运行」/ Site 链接，直接开始对话。

---

## 一、你只需要做一件事：说人话

打开就能用。**不用挑功能、不用填表格、不用运行任何脚本、不用在几个应用之间复制粘贴。**

直接说你现在要解决的经营问题，比如：

- 「这周想把要发的内容定下来。」
- 「我们四个账号一直各发各的，帮我理一下谁该做什么。」
- 「这条内容的口播稿帮我写出来。」
- 「下个月上新那一波，内容排期怎么安排？」

系统会自己判断该调用哪一项专业能力。**你不需要知道有哪些能力，也不需要说出它们的名字。**

有资料就直接上传（`.txt` / `.md`）。上传是可选的，不上传也能用。

---

## 二、它会做什么

按你这一轮说的事，只调用**用得上**的部分：

| 你在做的事 | 它会动用什么 |
|---|---|
| 描述经营问题、聊需求 | 只记录上下文，不启动任何专业能力 |
| 要一份专业产物 | 读当前经营状态 → 做周期判断 → 进入那一项专业能力 |
| 说「已经发出去了」 | 登记一条**测试发布记录** |
| 给反馈数据 | 按版本写回，重复提交不会记两遍 |
| 说「这份素材别用了」 | 标记为不再复用 |

**不是每次都跑全套。** 用不上的部分不会跑，也不会偷偷替你跑。

---

## 三、它不会做的事（这些是硬边界，不是暂时没做）

- **不会连接任何真实内容平台，也不会真的发布任何东西。** 所有发布记录都显式标为测试与模拟。
- **不会替你挑商品，也不会替你定内容方向。** 缺关键信息时它会停下来问你**那一项**，不会自己补一个。
- **资料不够时不会整件事拒绝。** 不依赖那项缺口的部分照常给你，只有会编造的那一支才停。
- **撤回素材不会影响已经发出去的内容。** 撤回改变的只是「以后还能不能用它做新内容」。
- **没有写成功的事，它不会说已经完成。**

---

## 四、看到这些是正常的

**它反问你一个问题** —— 说明差一项关键信息。补上那一项就行，前面说过的不用重说，已经做完的不会重来。

**它说「这一步没跑完」** —— 是系统调用出了问题，不是你的输入有问题。说一声就能从这里接着做。

**同一个对话里可以一直聊下去** —— 账号、周期、已完成的产物都记着，换一句话继续说就行。

---

## 五、当前状态与未验证事项（如实告知）

- 这是**测试域**：每个新对话会自建一套隔离的测试工作区与测试账号，写入的都是测试数据。
- **真实平台发布、真实经营提升（涨粉、成交、到店）均未验证**，本应用也不承诺。
  反馈数据是你手工告诉它的观察，不代表真实平台效果。
- M5 阶段已接受的八项技术债（`TD-M5-01..08`）**未在本轮偿还**，仍然有效。
