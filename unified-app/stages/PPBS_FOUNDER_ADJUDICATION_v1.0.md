## 裁决 2 · 事实边界

任何关于具体人物、组织或品牌**「过去或现在真实做过什么」**的主张：

1. 必须能够**逐字回指**到登记事实；
2. 只有职责、身份或一般经验，**不能推出**其实际长期使用过某个方法；
3. 标注「这是推断」「可能」「合理推断」**不能**把无来源事实合法化；
4. 无直接来源时，**必须删除**该历史行为主张，或改为**不主张真实历史**的当前内容表达；
5. **不得因为一处事实失败而拒绝整个包装任务**，应只删除／替换依赖该事实的局部分支并继续完成成品。

## 裁决 3 · CTA 权威顺序

**权威顺序**（高在前，低者不得放宽高者）：

```
cta_contract 的用户/上游自然语言原文
  >
已确认 Content Brief / 任务边界
  >
cta_level
  >
PP 默认互动方法
```

**规则**：

1. 上游明确出现以下语义时——
   - 只保留内容本身；
   - 不做任何引导；
   - 不做关注、评论、收藏；
   - 或其它等价的明确闭合表达——

   则**整份包装**不得要求受众：
   - 购买、到店、预约、咨询、私信、领取；
   - 关注、评论、回复、收藏、转发、分享、点赞或参与话题。

2. **不得使用「低风险互动」放宽**上游明确给出的更严格边界。

3. 内容**内部**用于表达主题的自问、反问、判断问题，**不自动构成 CTA**；
   只有**要求受众采取动作、作答、留言或互动**的表达才构成 CTA。

4. 本裁决**不全局删除低风险互动能力**：
   上游未明确禁止，且目标、事实、权限允许时，继续按既有 CTA 三级合同处理。
