> 它是判断辅助，**不是平台规则副本，也不是静态行业真源**。

## 1. 先把商品经营画面拼出来

只用**相关、当前、有来源**的事实：

| 维度 | 要知道什么 |
|---|---|
| 商品阶段 | 上新／在售／补货／促销／退场／未知 |
| 商品关系 | 主推｜配套｜搭配补充｜仅门店｜其他有证据的角色 |
| 季节与气候 | **地域**季节和气候，不是笼统的"全国换季" |
| 可售性 | 颜色 × 尺码 × 渠道 × 时间 |
| 补货与清货 | 补货可能性、退场压力 |
| 商品事实 | 材质、版型、工艺、保养、价格 |
| 试穿 | **试穿事实**与**可用的试穿素材**是两件事 |
| 使用场景 | 真实穿用场景与顾客决策问题 |
| 承接路径 | 小程序、咨询、到店或其他路径**各自**是否真的可用 |
| 门店 | 位置、营业时间、现场库存、服务能力、可兑现体验 |

**不得用未经核实的行业通则压过具体商品事实。**

---

## 2. 内容单位怎么定

优先：

```text
顾客决策问题
+ 相关的商品关系
+ 当前真的能兑现的路径
```

**不要**把一个内容单位等同于一个 SKU 或一次泛泛的商品介绍。

- 顾客决策确实需要比较时，一条任务**可以**比较多个商品；
- 同一商品在**决策问题或承接路径实质不同**时，**可以**支撑不同任务。

## 3. 局部失效表

| 变化或缺失 | 失效／受限的 | **仍然有效的** |
|---|---|---|
| 某颜色/尺码不可得 | 相关可售性、CTA、时效、受影响的那条任务 | 材质与工艺事实、其他不相关的款色 |
| 补货变得不确定 | 承诺、紧迫感、活动窗口 | 已核实的商品事实 |
| 价格或优惠到期 | 价格/优惠主张、转化型任务 | 承诺仍成立的非价格内容 |
| 没有发生过试穿 | 需要上身证据的主张 | 材质、细节、保养、搭配原则、平铺等有支撑的内容 |
| 试穿发生了但素材不可用 | 依赖该素材的**生产路径** | 已核实的观察本身（若另有来源且获授权） |
| 门店接不住当前需求 | 到店 CTA 与门店可得性主张 | 仍然有效的非门店路径 |
| 季节/气候窗口变了 | 场景相关性与时机 | 不依赖该窗口的长效事实 |

**永远不要**把"当前不可售"变成"商品事实是假的"。
**永远不要**把"没有试穿素材"变成"服装内容都做不了"。

## 4. 声明要匹配证据

| 主张 | 需要什么 |
|---|---|
| 版型、垂坠、动态、体感、比例 | 相应的上身证据，**或**显式写出不确定 |
| 成分、结构、尺寸、保养、价格、库存 | 当前的权威商品数据 |
| "适合某场景" | 商品属性与该场景之间站得住的关联 |
| 顾客偏好 | 观察，**不是**泛泛的时尚通则 |
| 稀缺、爆款、显瘦、高级 | 各自单独的支撑 |

证据缺失时：**降低主张强度｜换一个任务｜把陈述条件化｜延期｜不发**。

**不要用听起来保守的数字或熟悉的行业套话填缺口。**

## 5. GMV、线索、到店不可互换

### GMV

盯住：购买决策摩擦、当前可售性、商品证明、比较、价格/优惠的真实性、真实存在的购买路径。

### 线索

盯住：值得咨询的理由、咨询之后能给到什么信息或服务、资格边界、响应能力、可靠的线索承接。**评论或点赞不自动等于线索。**

### 到店

盯住：为什么线下这一趟能提供线上没有或更弱的价值、谁该来、地域与时间、门店现货与体验、服务能力、诚实的到店路径。**不得从"线上可售"推出"门店可承接"。**

三者可以并存，但它们的**任务与观察目标不可互换**。

## 6. 主动发现机会

机会假设由这些拼出来：

1. 当前的需求、注意力、行为、供给或时机信号；
2. 它的平台、地域、品类、受众和时间**范围**；
3. 证据强度与已知偏差；
4. 账号与表达适配；
5. 商品或运营上真的能兑现；
6. 一个独特的顾客决策问题或价值缺口；
7. 最小可逆的内容/运营动作；
8. 预期可观察的反应与反证；
9. 到期或复验条件。

可能的决定：**筛除｜只观察｜做有边界的验证｜在当前产能内利用｜停止或重新设计**。

**不要混淆四件事**：

| | 是什么 |
|---|---|
| **机会** | 有范围的信号 + 适配 + 供给/路径 + 可逆测试 |
| **追热点** | 只有注意力信号，没有账号或业务适配 |
| **同质化防御** | 避开拥挤表达，但并没有正向需求证据 |
| **不适配的机会** | 市场信号真实，但账号无法可信地表达或兑现 |

## 7. 同质化责任分层

| 层 | 归属 | M3 的动作 |
|---|---|---|
| 品类/赛道机会、题材饱和、内容支柱平衡、栏目疲劳、周期集中度 | **M3** | 改周期组合、时机、资源投入，或决定去验证 |
| 单条内容的切入、钩子、叙事、表达机制 | 创意锦标赛／Creative Script | 保留真实备选空间，**不规定机制** |
| 标题、封面、入口承诺、平台包装 | Publishing & Packaging | 传事实与约束，**不写包装** |

可靠、当前、范围匹配的外部证据，**可以**在没有账号衰退证据的情况下支持一次轻量可逆动作。**永久退出或长期重新定位需要更强的账号自身证据**，重新定位返回 Matrix。

**没有市场证据时**：可以基于内部证据继续生产，但必须说明"外部比较不完整"。**永远不要**在没有当前范围匹配证据时声称平台唯一或稀缺。

## 8. 工具与时效边界

决定确实依赖平台与市场情况时，**运行时读当前来源**。**不要把易变的平台规则抄进本文件。** 保留来源、平台、观察时间、范围和新鲜度。

第一个切片**不建设**自动监控、评分或优化平台。只有真实运行证明确实需要日期窗口、产能算术或去重时，才加最小的确定性工具，且**优先放在数据层或应用层，不放进专业判断文本**。
