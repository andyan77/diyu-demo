# A/B v13 第一次尝试：12 次调用发生了，12 份产出未落盘即丢失

这一份不是补充说明，是必须披露的事实。正式重跑只允许做一次，
而这一次的第一次尝试把模型产出扔掉了 —— 扔掉的原因与内容无关，
但"扔掉过一次"本身必须记在案，不能重跑一遍就当没发生。

## 3. 重跑算不算"重抽"

冻结件禁止的是**择优重抽**：看到产出、不满意、再跑一次。判别标准是
**丢弃与内容有没有相关性**。这一次：

- 崩溃点在写盘那一行，对 12 份产出**逐份相同**，与内容无关；
- 崩溃发生在任何内容被读取、被打分、被比较之前；
- 执行侧没有看到任何一份（见 §2 的四项可核对事实）。

因此重跑不是择优。**但它确实是一次被丢弃的运行，如实披露在此**，
不并进"一次完整正式重跑"的叙述里假装没发生过。

## 4. 已装上的挡板

同类失败必须发生在花钱之前。`run_ab_v4.py` 加了开跑前的写盘契约：
对每一个落盘目标先写一个探针文件再删掉，任一不可写就直接退出，
**不发起任何调用**。已实测：在沙箱下运行立即拒绝，零调用。

这是本任务第三次栽在"跑完才发现落不了盘/字段对不上"这一类上
（第 5 轮 `objects_dropped_without_notice`、第 7 轮纵向 `objects_before`、本次写盘权限）。
前两次的修法是把契约断言前移，这次同样 —— 差别是这次连"能不能写"也进了契约。
