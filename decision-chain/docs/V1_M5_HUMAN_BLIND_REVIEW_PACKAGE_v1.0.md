### 怎么评

每一组分两层判，**先判硬门，硬门不过就不用看增益**：

1. **硬门（不退化）**：逐条判「乙相对甲有没有退化」和「甲相对乙有没有退化」。
   任何一条退化，那一份就在硬门上失败。硬门只判有没有退化，不判谁更好。
2. **增益（整体）**：硬门都过之后，再判在**适用**的专业维度上，
   哪一份形成了整体增益。不要求每一项都赢，也不要求六项都适用。

### 判「退化」的口径

- **目标退化**：把用户声明的目标换成了别的目标（比如把「涨粉」悄悄写成「长期价值」），
  或者根本没回应用户声明的目标。
- **事实退化**：写了资料里没有的商品性能、价格、库存、优惠、顾客案例或经营结果；
  或者把「待确认」写成了确定。
- **权限退化**：承诺了没有确认的承接（预约、到店、专人接待、时效、容量），
  或暗示了这些。
- **风险退化**：制造身材/年龄/身份焦虑；用无依据的绝对化话术；
  替观众下「适合你 / 不适合你」的结论。
- **模块责任退化**（仅 AB-M3-01）：越过自己的职责去替下游做决定，
  或该自己给的判断没给。
- **必要经营能力退化**（仅 AB-FINAL-01）：成品拿到手里做不出来
  （班底、时间、素材对不上），或者缺了发布必须的东西。

**结论**

这周只发一条内容，用来验证“顾客能不能自己判断哪件衣服适合自己”这个方向立不立得住。我把这轮定位成方向验证：账号本周期还没有任何发布和反馈，没有可信的观看理由，所以先用一条内容测试最关键的假设，而不是铺开四条。

**关键依据和假设**

- 账号本周期没有发布与反馈，所以我只能依据品牌事实和你的描述做暂定判断。我先把账号的表达主体暂定为“序里集品牌”，依据是品牌事实里对品牌价值的描述；这个暂定只用于本轮，不推导长期人设；不确定性在于品牌号未来如果由多人出镜，需要明确统一的表达主体；如果这次内容发出后，观众开始询问“你们家是谁在选品”，就得回到长期定位环节重新确认。

**这轮的内容任务**

我给这周安排一条内容任务，业务上做这样一件事：让观众用几个具体的判断标准来评估一件衣服适不适合自己，而不是由品牌直接替她下结论。内容需要给出可操作的自查维度（比如这件衣服在你的衣橱里承担什么角色、和你已有的鞋包外套能不能组成场景），并可以引用目前可公开的选品比较和试穿记录来支撑“适不适合取决于个人衣橱和场景”这个观点，但不能替观众做决定。删掉它，本周期就得不到任何关于这个方向的证据，下一周期只能继续盲试。

这次试水的边界是：要验证的不确定点是顾客是否愿意并能够用自己给出的框架来判断，而不是只依赖品牌推荐；最小动作就是发布这一条内容，只给出判断框架，不加任何强CTA；如果评论或私信里出现“我属于……所以……”“我按你说的看了……”这类观众用框架自述的表达，说明方向可以继续；如果一周内完全没有这类反应，或者评论区大量出现“还是不知道”“你直接推荐吧”，就说明方向需要重新设计而不是继续加码；复盘时点定在本周期结束，到时看评论和收藏数据再决定下一步；它让位的是本周另外三条发布预期，用数量换方向清晰度。由于账号还没有建立任何稳定栏目，没有已有的稳定义务被让位。

这四件通勤单品，我不打算告诉你买哪件。

不是因为哪件不好，而是它们在你衣橱里承担的任务不同。同样一件廓形西装，有人用来盖住会议里的正式感，有人用来压住周末聚餐的随意感——它到底适不适合你，取决于你穿着它要面对什么，不取决于我这边觉得它好不好看。

所以我们做了一件事：没有给你列必买清单，而是把「怎么判断」拆给你看。

你只需要回答四个问题：

一、你要穿着它出席的场合，是什么性质的？
二、你衣橱里已经有的外套、鞋、包，能和它组成几套？
三、你打算在最外层穿它，还是把它穿在中间？
四、如果穿上后有一个地方不舒服，是你调整穿法能解决的，还是版型本身的问题？

这四条不保证你最后一定选中我们家的衣服。它们只保证一件事：你筛掉的，都是本来就不该留下的。

我们内部在做选品比较的时候，就是先排掉不合适的那一半，才轮到谈哪件更好看。

内容里具体的比较逻辑和试穿观察都在视频里，你可以自己对着看。

如果你看完之后，发现自己其实不太确定某个具体问题——比如你那件西装到底该不该买——那正是需要你来店里试穿的原因，不是看视频能解决的。
