## 二、专项问题逐项结论（M0P-C01～C08）

> 本节及 §五、§八 中出现的"共享合同一／二／三／四"编号与内容范围，**来自本任务 Execution Prompt §12-15**（任务上下文快照／八项能力／版本发布反馈归属／写回权限幂等恢复），**不是** v0.2 自身的编号——v0.2 §10.1 只列了三类预检对象（起始资料与任务上下文／最小业务数据／Dify 集成），不等同于四份共享合同的划分。v0.2 §3-§7 是四份共享合同据以起草的业务语义素材来源，不是编号来源。

### M0P-C01：最短合法接入点

**结论：单账号持续运营目前没有独立入口——因为该能力本身 `MISSING`（通用 EP-00 §二·能力3）。当前唯一可复用的最短合法路径，是绕开决策链、直接从生产链侧的自由文本输入进入。**

- 主链路由是纯 Skill 路由（通用 EP-00 §三.1），无经营目标路由；`UPSTREAM_OF` 把八项能力中的五个串成单向线性锁（§三.3），Matrix 是唯一无上游依赖的入口。
- **已验证的旁路**：生产链 Stage 1 把 `content_brief` 当普通自由文本 `Start` 变量接收，**从不调用 Content Brief App**（§五.3）——任何来源的 Brief 文本（粘贴的、历史的、手写的）都能不经过 Campaign/Content Brief 直接进入 Creative Script。仓库里**每一次**生产链真实运行走的都是这条路径。
- 六份独立 Dify App（Creative Script／Production Director／Publishing & Packaging／三个决策链 Tool）均可脱离主链直接运行（§三.4），但要求调用方手填 11–12 个槽位，**不是**普通用户对话可达的入口——这只证明"操作员可手动驱动"，不证明"用户可直接到达"。
- **对单账号持续运营的直接含义**：既然该能力尚不存在，"进入"这件事目前只能通过下游能力（Content Brief 及以后）以文本形式吸收运营决策结果，而不能通过一个真正的持续运营组件产生这些决策。这正是四个共享合同要冻结的接缝——共享合同一「任务上下文快照」与合同二「八项能力」的合法等价输入语义，必须能覆盖"运营决策以文本形式跨过尚不存在的组件直接进入下游"这一当前唯一现实路径。

### M0P-C02：起始资料与任务上下文

**结论：结构化承载全面 `MISSING`（通用 EP-00 §三.2），当前只有 9 个会话变量、其中业务语义相关的仅 2 个不透明目标字符串。**

主目标/次目标/优先级/不可牺牲条件/账号阶段/表达裁量/期望发布量/实际产能——全部没有一等字段，能找到的形式要么是硬编码进夹具 Prompt 文本（表达裁量、实际产能），要么全仓零命中（次目标、优先级、账号阶段、期望发布量）。任务快照 `task_snapshot_json` 必需 13 键，业务语义相关的只有 `draft_task.goal`/`confirmed_task.goal` 两个自由文本字符串。这直接对应共享合同一（任务上下文快照）要冻结的业务语义清单——当前**没有任何一项**已经结构化存在，共享合同一是从零冻结语义，不是对既有结构的重命名。

### M0P-C03：业务持久化与运营记忆

**结论：100% 持久化状态落在 Dify 内部会话变量，跨会话零延续，不存在业务真源（通用 EP-00 §八.3）。**

## 四、F-10 当前风险核验（M0P-C07）

> v0.2 §5.12 是 Founder 在下位合同定向纠偏轮次新增的产品裁决，通用 EP-00（2026-08-24 早于该轮次完成）未覆盖此分析，本节是本报告唯一的"从零核验"部分。

### 风险 A：既有 Skill 把流量、起号或 GMV 目标重新改写成长线价值任务

**结论：没有发现"检测到增长目标后自动替换为长期价值目标"的机制或证据；但存在一处相邻、需要如实呈现而非回避的证据——Campaign 的主目标类型本身被锁定为"认知变化"。**

- Matrix Architect 把"长期价值"列为**禁用抽象词**（通用 EP-00 §四.1，`:170`），是排斥而非改写。
- Campaign Orchestrator（通用 EP-00 §四.1 完整行）：**Q1** 列记载"主目标**类型**被锁定为认知变化（`:110`）"——这是六份 Skill 中与"目标忠实"最直接相关的一条证据，不能省略；**Q2** 列另有 3 处（`:107+:110` 到店/成交/复购降为"经营结果"层不得并列主目标、`:120` 禁用增长语言表述、`:207+:209` 剥夺互动/播放/点赞决策权）。这四处共同构成的实际图景是：**Campaign 当前把主目标的"类型"锁定为认知变化，并把经营信号系统性降权**——这比"改写为长期价值"更精确的描述是"目标类型被窄化＋经营信号被降权"，两者都对 §5.12.1"经营目标不得被静默改写"构成压力，即便不完全等同于"改写"本身。
- **本次核验没有发现"改写"意义上的风险 A 已经发生**，但 Campaign 的目标类型锁定与信号降权是真实存在、需要在共享合同二冻结"八项能力合法输入"时明确排除的相邻风险——不应被本节的"无证据"结论掩盖。这与 C-2（工程投影层外部注入 `RUN_MODE`）是同一根因的两个视角。

### 风险 B：组件化为避免风险 A，旁路或削弱真正有价值的专业方法，最终产出普通廉价流量套路

**结论：当前机制层面尚不构成"组件化"（八项能力中五个仍是线性锁，通用 EP-00 §三.3），风险 B 目前没有触发条件，但 v0.2 §5.12.2 一旦落地组件化按需调用，需要提前识别的边界已列出。**

- 当前没有任何"按需跳过组件"的运行时机制——`gate_reason()` 强制线性上游，无旁路（§三.3）。风险 B 描述的是"未来一旦允许按需调用后可能出现的退化"，不是当前已发生的事实。
- v0.2 §5.12.2 已经预先写入防线："跳过组件不等于放弃当前任务真正需要的能力""下游输入合同只能要求完成当前下游工作必要的内容，不得要求用户复制完整上游产物"，且原文显式声明"本条约束的是产品运行时的按需调用，不放宽 §5.11……与验收要求"——本报告核验这些条款与 §5.11/§8.3 P0-1/P0-2 之间没有发现冲突。
- **本报告发现，供 Phase B 参考（建议，非强制裁决）**：六份 Skill 中真正承担"专业方法"的部分（CS-1 差异判据、PP 四道确定性闸、语义事实核验）目前全部嵌在具体 Tool/App 内部，未被抽象成可独立调用的方法层。共享合同二起草"合法等价输入"时，如果把"下游必要条件"泛化到可以被无专业含量的最小合规输入满足，组件化可能滑向风险 B 描述的退化——这是一条边界提醒，具体措辞如何冻结留给 Phase B 起草与 Founder 裁决，本报告不代为决定。

### 风险 C："专业能力义务"膨胀为全能硬门，迫使每个任务经过全部 Skill 或补齐无关资料

**结论：风险 C 描述的两半图景需要分开看——"横跨全部六份 Skill 的强制门"目前不存在；但"因资料不足对整个任务硬停、无降级通道"这一半，在决策链侧（尤其 Matrix）已经真实存在，且已被通用 EP-00 判定为六份 Skill 中最严重的一处、与 CLAUDE.md §4 直接冲突。这不是"风险 C 尚未发生"，而是"风险 C 的一种变体已经发生，只是发生的位置不是六个 Skill 全部串联，而是单个能力内部的整任务硬停"。**

- 通用 EP-00 §二·能力1 明确记载：Matrix 资料不足时**整任务硬停**（`INPUT_INSUFFICIENT` 后禁止追问/降级），是"六份 Skill 中最严重的一处"，与 CLAUDE.md §4"资料不足时不得整任务拒绝"直接冲突；§四.5 进一步确认决策链三份（Matrix/Campaign/Content Brief）**全部**走整任务硬停、无降级通道，与生产链三份"产出能产出的部分"的方向相反。
- 这正是 §5.12.2"非关键专业建议不得阻塞整个任务"要防止的模式的一个已经存在的实例——只是触发它的不是"专业能力义务膨胀"，而是决策链侧既有的资料完整性判据本身就是全有全无式的。**共享合同二／四起草时需要如实承接这一发现**，不能因为"风险 C 尚未发生"的字面判断而遗漏这处真实存在的过度阻塞。
- v0.2 §5.12.2 的例外允许清单本身是**封闭列举**：只有"事实、权限、合规、用户明确不可牺牲条件、当前下游确实无法运行的必要输入缺失，或 §8.7 已点名的门禁项"五类可以阻止任务推进；"不缩减 §8.7 已冻结的门禁清单"这一句是**下限声明**（保证 §8.7 门禁不因本条被削弱），不构成"该清单不能扩大"的证据——清单封闭性来自枚举本身是闭合列举，不来自这句下限声明。Phase B 起草共享合同二／四时应保留这个闭合列举，不把"下游必要输入"泛化到能覆盖"建议性专业资料"，否则会重新制造出风险 C；这是本报告的起草建议，具体措辞与是否采纳仍需 Phase C／Founder 确认，不由本报告直接裁定。

**F-10 三风险汇总结论**：风险 A 的"改写"意义上未发现证据，但 Campaign 的目标类型锁定是需要如实呈现的相邻证据；风险 B 目前无触发条件，是纯预防性边界；**风险 C 的"整任务硬停无降级通道"变体已经真实存在于决策链侧，不是纯预防性的**——这是本报告与最初判断不同、修正后的结论。三处都需要在 Phase B 起草共享合同时被准确承接，具体措辞与取舍留给 Phase B／Phase C，本报告只登记事实与建议，不代为裁决。
