## 二、服装 IP 矩阵专章

### 2.1 公开案例中出现的五种账号基础形态

本节按“账号为何存在、由谁表达”分类。第九章的“公转私型 / 同城到店型”按“在哪里成交、由谁承接”分类，属于另一维度；二者可以组合，不能相加后当成同一维度的七种互斥账号形态。

| 形态 | 代表 | 适用条件 | 核心机制 |
| --- | --- | --- | --- |
| 货盘店群型 | 鸭鸭 200+ 号、波司登 | 多 SKU、标品化程度高、投流预算大 | 按品类×人群拆店，每号独立组货养标签，无人设 |
| 老板/专家人设店播型 | 霞湖世家、洪陵羊绒 | 有真老板/真专业可出镜 | 真实身份讲专业（面料、工厂、价格逻辑），高势能信任 |
| 导购 KOS 型 | 绫致、VERO MODA 城市号 | 门店多、导购稳定 | 导购真人真岗位＋企微私域承接，栏目化固定直播 |
| 供应链身份型 | 四季青老板娘 | 档口/工厂背景 | "身份即内容"：穿版、报价、凌晨档口氛围 |
| 买手审美信任型 | 董洁、章小蕙、Akikiyu | 高客单、有审美人格 | 慢直播、低频高质、小粉丝量高转化 |

### 2.2 服装垂类的候选风险（与其他行业不同的部分）

1. **高退货率可能限制矩阵扩张**：罗拉密码月销过亿仍主动闭店（自述退货 80-90%＋运费险＋投流失控）；张大奕 2024 关店自述同因；2024-2026 出现女装百万粉店闭店潮。扩张是否放大退货亏损，需要结合真实业务判断。
2. **中间定位可能承受两端压力**：公开案例分别出现高客单信任慢直播与低客单投流快周转；是否适用于序里集仍需 Founder 判断。
3. **跟款周期短可能削弱内容防御**：相关材料出现一周级跟款描述，不能据此直接推导所有原创白牌的内容周期。
4. **IP 零售与批发渠道可能发生价盘冲突**：十三行 2021、四季青 2023 两次官方禁播可作为风险提醒，具体因果仍以案例来源为限。
5. **公开模板缺口**：当前材料中未找到实体女装集合店主理人的具名成功矩阵模板。因此没有现成答案可抄，调研也不能替 Founder 作业务判断。

### 2.3 公开案例中出现的候选做法

公开案例中出现过以下做法：现货优先于预售、真实多模特试穿（含不同身材差异化人设）、店播矩阵降低对超头的依赖、会员私域复购降低纯投流拉新依赖，以及在高退货压力下收缩中间定位。这些是定向追问线索，不是对所有女装业务都成立的通用处方。

## 三、美妆专章（对照行业：哪些可搬，哪些不能搬）

### 3.1 五种结构与结局

| 结构 | 代表 | 结局给出的教训 |
| --- | --- | --- |
| 虚拟统一人设＋私域 | 小完子 | 起量极快，但"表演型人设"被识破后信任折旧，撑不起复购 |
| 短剧脉冲＋自播承接 | 韩束 | 40 亿播放能变 33 亿 GMV 靠 17 个自播号承接；玩法红利约一年，只能当脉冲不能当信仰 |
| 概念 IP（无人格） | 珀莱雅"早C晚A" | 案例显示方法论心智可被多人复用，并降低对单一人格的依赖 |
| 大师人格 | 毛戈平 | 30 年真实手艺撑 80% 毛利；但人不可复制、传承无解 |
| 外部超头依赖 | 花西子×李佳琦 | 销售结构单点化＝把品牌人格抵押给别人，对方翻车无差别传导 |

### 3.2 可迁移到女装集合店的 5 条

候选迁移方向包括：「1 品牌号＋X 门店号＋N 导购 KOS」框架与中台支持（培训/激励/账号资产管理）；真人真岗位人设；概念 IP 化（服装可探索体型公式/场合衣橱/胶囊搭配方法论）；提高自有账号占比以降低外部依赖；为内容流量准备清晰的下一步承接。是否采用、如何采用，仍需 Founder 与真实试点判断。

### 3.3 不可迁移的 5 条（美妆特有）

成分党科普的内容母题（服装缺同等强度的客观知识层）；标品大单品年复一年复购（女装非标＋季节＋尺码退货）；功效宣称型监管红线形态（服装雷区在质检与价格，不在功效）；超头直播的品类适配（试色即内容，服装非标性天然弱一档）；大师手艺可视化演示（选品眼光难直接表演，需转译为改造类内容）。

## 四、创始人 / 员工 IP 专章

### 4.1 成功样式

| 样式 | 代表 | 机制 |
| --- | --- | --- |
| 创始人超级 IP＋高管矩阵 | 雷军＋卢伟冰等 | 单号做心智、矩阵接问题；栏目"答网友问" |
| 老板人格＋官号人格双引擎 | 束从轩＋"咯咯哒" | 官号人格属于品牌、可换人不塌房 |
| 家族短剧 IP | 毛巾少爷（真爷爷真爸爸出镜） | 真人真关系真工厂＋自嘲反差 |
| 二代 IP 与接班解耦 | 特步：姐姐当 CFO、妹妹做流量 | IP 是"年轻化天线"，不是经营者 |
| 价值观制度化 IP | 于东来/胖东来 | 企业制度本身即内容；正在做"IP 制度化退场" |

### 4.2 结构性风险（每条都有真实代价）

1. 单点依赖：薇娅一夜封禁罚 13.41 亿、张兰系账号被封抽走麻六记抖音近 40% 销售、如涵靠张大奕一人过半营收终至退市。
2. 员工 IP 盖过东家：董宇辉小作文事件一周掉粉 353 万、市值蒸发 75 亿港元、CEO 下台；最终"7658 万转股＋利润相赠"体面分手，东家由盈转亏。
3. 归属不清：李子柒商标在资本方手里停更 565 天、品牌年销从 16 亿跌到 6.76 亿；浪胃仙操盘手转移账号获刑 8 年；枝繁繁离职带 IP 起盘竞品。司法判例四要素：合同约定、实名注册、运营投入、粉丝来源。
4. 人设外溢：家事（张兰封号）、私德（张大奕）、情绪化发言（于东来扬言关店）、师徒连坐（三只羊全矩阵陪葬）。
5. 流量-转化落差：周鸿祎、毛巾少爷与立白总裁号材料显示，高曝光未必对应稳定转化；高势能人设是否更适合脉冲而非日常内容，属于待判断的候选观察。

### 4.3 案例中的常见应对方式

矩阵化去单一 IP（蜜蜂惊喜社/交个朋友）；账号公司化持有＋书面权属协议（判例背书）；体面分手预案（提前承诺归属，与辉同行模式）；IP 退居幕后（薇娅转幕后、罗永浩减出镜）；IP/品牌/产品三层防火墙（虎嗅提法，麻六记事后实践）；商标竞业与内容红线前置；数字人只做真人授权分身（无人直播会被平台禁播，2025-09 起 AI 内容强制标识）；平台合规框架内开号（抖音一店≤10 授权号、命名=品牌+人格化后缀）。

## 五、跨案例候选观察（十条，每条注案例）

1. **真实资产绑定可能提高人设可信度**：真老板（郭长棋）、真手艺（毛戈平）、真报表（于东来）、真档口（爱丽）与表演型人设案例形成对照；是否产生溢价仍需真实业务验证。
2. **栏目化可能提高内容持续性**：答网友问（雷军）、38 集接班 vlog（特步千金）、100 天日播（洪陵）、家族短剧连载（毛巾少爷）提供了候选观察。
3. **“货盘×人群”可作为候选切分维度，内容创意是另一层**：鸭鸭 200 号按品类人群拆、波司登按价格带拆；是否适用于集合店仍需 Founder 判断。
4. **人格分层是候选安排**：案例提示老板/专家可承担背书与脉冲，店员等角色可承担日常内容；单一案例不能证明高势能角色普遍不适合日常表达。
5. **先跑稳一个号再开矩阵是候选顺序**：案例材料中出现“主号月销 300 万再开矩阵”的行业说法，该数字仅是案例启发，不是通用门槛。
6. **承接结构可能影响流量能否转成下一步行动**：韩束与 KOS 材料提供了候选观察；当前只追问用户下一步做什么、谁在哪里接、是否接得住。
7. **大单品可以成为 IP 与生意的转换接口**：红蛮腰、山茶花油、赵露思同款大毛领提供了案例启发；IP 流量也可能落到到店、预约、会员或咨询，不预设必须落到单一商品。
8. **培训、激励和账号资产管理可能影响矩阵下限**：案例提示腰尾部账号的平均执行水平值得关注，但不据此直接设计当前 Demo 的治理系统。
9. **利益对齐可能影响参与意愿**：霞湖世家与鸭鸭材料提供了分红、分销案例；Skill 不负责设计分钱，只在明显不对齐时提示 Founder。
10. **概念 IP 可作为人格 IP 的候选补充**：珀莱雅"早C晚A"提供了方法论心智可被多人复用的案例，不代表所有行业都应采用。

### 9.5 候选适配信号（使用时需真实试点判断）
